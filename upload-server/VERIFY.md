# 文档识别功能验证指南

## 一、验证 VPS 上传服务

### 1.1 服务是否运行
在浏览器访问：
```
http://你的VPS公网IP:3001/ping
```
**预期结果：** 返回 `{"ok":true}`

### 1.2 文件上传是否正常
用 curl 或 Postman 测试上传：
```bash
curl -X POST http://你的VPS公网IP:3001/upload \
  -F "file=@测试文件.pdf"
```
**预期结果：** 返回 JSON，包含 `url` 字段，如：
```json
{
  "url": "http://你的VPS公网IP:3001/uploads/171718xxxx-xxx.pdf",
  "filename": "171718xxxx-xxx.pdf",
  "originalName": "测试文件.pdf",
  "size": 12345
}
```

### 1.3 上传的文件能否公网访问
把上一步返回的 `url` 直接粘贴到浏览器地址栏。
**预期结果：** 浏览器能正常下载/预览该文件。

## 二、验证本地项目配置

### 2.1 设置页面配置
1. 打开本地项目：`http://localhost:3000`
2. 进入 **设置页面**
3. 确认"文件上传服务器地址"已填写：`http://你的VPS公网IP:3001`
4. 点击**保存设置**

### 2.2 数据库是否写入
如果你会查数据库，确认 `user_settings` 表的 `fileServerUrl` 字段有值。

---

## 三、验证文档识别全流程

### 3.1 进入文档识别面板
1. 打开 **题库页面** (`/questions`)
2. 点击右上角的 **"文档识别"** 按钮
3. 应弹出文档识别面板

### 3.2 上传文件
1. 点击"选择文件"，上传一个 **PDF 或图片**（建议先用一个包含 1-2 道题目的简单文件测试）
2. **预期结果：** 页面显示"xxx.pdf 上传成功"，且"已添加的文件"列表中出现该文件

> 如果提示"请先在设置中配置文件上传服务器地址"，返回第 2.1 步检查。

### 3.3 开始识别
1. 选择题型（如"单选题"）、数量（建议先选 1-3 道）、难度
2. 点击 **"开始识别"**
3. **预期结果：** 按钮显示转圈加载，约 5-15 秒后弹出"成功识别 N 道题目"，下方显示识别结果预览

### 3.4 检查题库
1. 点击"全部题目" Tab
2. **预期结果：** 新识别的题目出现在列表中，带有"AI"标签
3. 点击题目可以进入答题界面

## 四、常见问题排查

| 现象 | 可能原因 | 排查方法 |
|------|---------|---------|
| `/ping` 无法访问 | 安全组/防火墙未开放 3001 端口 | 检查阿里云安全组 + `sudo ufw status` |
| 上传成功但 URL 打不开 | `PUBLIC_URL` 未配置或配置为内网 IP | 检查启动时的 `PUBLIC_URL` 环境变量 |
| 前端提示上传失败 | 跨域问题或 VPS 服务崩溃 | 查看 VPS 上 `server.js` 的终端输出 |
| 识别成功但题库没有新题 | 后端报错或 AI 返回格式错误 | 查看本地后端控制台（运行 `npm run dev` 的终端） |
| AI 识别结果为空 | 文件内容确实没有题目 / AI 模型不支持该格式 | 换一个有明确题目的文件再试 |

### 查看日志

**VPS 上传服务日志：**
直接在运行 `node server.js` 的终端查看实时输出。

**本地后端日志：**
在运行 `npm run dev` 的终端查看 `[chatWithAI]` 相关的请求日志。

## 五、快速诊断命令

在 VPS 上执行：
```bash
# 检查服务是否在监听 3001 端口
sudo ss -tlnp | grep 3001

# 检查 uploads 目录是否有文件
ls -la /root/upload-server/uploads/

# 检查服务状态（如果用了 systemd）
sudo systemctl status upload-server
```

在本地电脑上执行：
```powershell
# 测试能否连通 VPS 的 3001 端口
telnet 你的VPSIP 3001
# 或
curl http://你的VPSIP:3001/ping
```
